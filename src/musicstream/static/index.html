    YouTube: условия и конфиденциальность
    MusicStream использует YouTube API Services. Для поиска выбранные название и исполнитель передаются через наш backend Google. При загрузке плеера браузер подключается к YouTube, который получает IP-адрес и может использовать cookies и показывать рекламу. Вход в аккаунт и просмотр регулирует YouTube. MusicStream не скачивает видео или аудио, не создаёт библиотеку и не сохраняет результаты YouTube; параметры запросов могут попадать в журнал backend. Снимите согласие, чтобы остановить и удалить плеер.
